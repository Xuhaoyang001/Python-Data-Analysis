# 第三题：Carseats 数据集多元线性回归分析报告

## 一、实验目的

通过对 `Carseats` 数据集进行多元线性回归分析，研究不同因素对儿童汽车座椅销售量（`Sales`）的影响。

主要完成以下任务：

1. 读取并查看 `Carseats` 数据集；
2. 建立以 `Sales` 为因变量的多元线性回归模型；
3. 将 `ShelveLoc` 作为分类变量处理；
4. 分析 `ShelveLoc[Good]` 的回归系数及其显著性；
5. 使用方差膨胀因子（VIF）检验多重共线性；
6. 通过 R2R^2 和调整后的 R2R^2 对模型进行评价。

## 四、Python 实现代码

```python
import pandas as pd
import statsmodels.formula.api as smf
from statsmodels.stats.outliers_influence import variance_inflation_factor

# 读取数据
data = pd.read_csv("Carseats.csv")

# 查看数据前5行
print("数据前5行：")
print(data.head())

# 查看数据基本信息
print("\n数据基本信息：")
print(data.info())

# 设置 ShelveLoc 分类变量
# Bad 作为参考组
data["ShelveLoc"] = pd.Categorical(
    data["ShelveLoc"],
    categories=["Bad", "Medium", "Good"]
)

# 建立多元线性回归模型
model = smf.ols(
    "Sales ~ Price + Income + Advertising + "
    "C(ShelveLoc, Treatment(reference='Bad'))",
    data=data
).fit()

# 输出模型拟合结果
print("\n================ 模型拟合报告 ================\n")
print(model.summary())

# 输出回归系数
print("\n================ 回归系数 ================\n")
print(model.params)

# 获取 ShelveLoc[Good] 的系数名称
good_name = "C(ShelveLoc, Treatment(reference='Bad'))[T.Good]"

print("\n================ ShelveLoc[Good] ================\n")

if good_name in model.params.index:
    print("ShelveLoc[Good] 系数：", model.params[good_name])
    print("P值：", model.pvalues[good_name])
else:
    print("没有找到 ShelveLoc[Good] 系数，请检查数据中的 ShelveLoc 分类。")

# 构造用于 VIF 检验的数据
X = pd.get_dummies(
    data[["Price", "Income", "Advertising", "ShelveLoc"]],
    columns=["ShelveLoc"],
    drop_first=True
)

# 将布尔/整数数据转换为浮点型
X = X.astype(float)

# 添加截距项
X.insert(0, "Intercept", 1.0)

# 计算 VIF
vif = pd.DataFrame()
vif["Variable"] = X.columns
vif["VIF"] = [
    variance_inflation_factor(X.values, i)
    for i in range(X.shape[1])
]

print("\n================ VIF 检验 ================\n")
print(vif)

# 输出模型评价指标
print("\n================ 模型评价 ================\n")
print("R² =", model.rsquared)
print("调整后的 R² =", model.rsquared_adj)
```

- VIF<5VIF<5：一般认为不存在明显的多重共线性；
- 5≤VIF<105\leq VIF<10：可能存在一定的多重共线性；
