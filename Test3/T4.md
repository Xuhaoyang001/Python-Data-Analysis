# Ridge、Lasso 与 Elastic Net 实证比较实验报告

## 一、实验目的

使用 Hitters 棒球运动员薪资数据，分别建立 Ridge 回归、Lasso 回归和 Elastic Net 回归模型，并使用 10 折交叉验证选择最优正则化参数 
$$
\lambda
$$
通过比较三种模型的测试集 RMSE 和非零变量数量，分析不同正则化方法在预测性能和变量选择方面的差异。

实验主要内容如下：

1. 使用 `RidgeCV`、`LassoCV` 和 `ElasticNetCV` 建立模型；
2. 使用 10 折交叉验证选择最优 $\lambda$；
3. 绘制三种模型的系数路径图；
4. 比较三种模型的测试集 RMSE；
5. 统计三种模型最终的非零变量数量；
6. 使用 1-SE 法则讨论是否应该选择更加稀疏的模型。

------

# 五、Z-score 标准化

Ridge、Lasso 和 Elastic Net 都包含正则化惩罚项。

如果不同变量的量纲不同，那么相同的正则化参数对不同变量产生的影响也会不同。

因此在建立模型之前需要进行标准化。

Z-score 标准化公式为：

zj=xj−xˉjsjz_j = \frac{x_j-\bar{x}_j}{s_j}

其中：

- $x_j$ 表示原始变量；
- $\bar{x}_j$ 表示变量均值；
- $s_j$ 表示变量标准差；
- $z_j$ 表示标准化后的变量。

代码如下：

```python
scaler = StandardScaler()

X_train_scaled = scaler.fit_transform(X_train)

X_test_scaled = scaler.transform(X_test)
```

需要注意，标准化参数只能由训练集计算。

测试集必须使用训练集得到的均值和标准差进行转换，以避免测试集信息泄露。

# 六、Ridge 回归

$$
Ridge 回归在普通最小二乘回归的基础上增加 $L_2$ 正则化项。

其目标函数为：

min⁡β[∑i=1n(yi−xiTβ)2+λ∑j=1pβj2]\min_{\beta} \left[ \sum_{i=1}^{n} (y_i-\mathbf{x}_i^T\beta)^2 + \lambda \sum_{j=1}^{p}\beta_j^2 \right]

其中 \lambda 为正则化参数。

当 \lambda 较小时，模型接近普通最小二乘回归。

随着 \lambda 增大，回归系数受到更强的压缩。

Ridge 的特点是：

λ↑⇒∣βj∣↓\lambda \uparrow \Rightarrow |\beta_j| \downarrow
$$

但是 Ridge 使用 $L_2$ 惩罚，因此通常不会使系数精确等于 0。

所以 Ridge 主要用于：

- 控制模型复杂度；
- 缓解多重共线性；
- 降低模型方差。

本实验使用 `RidgeCV` 并设置：

```python
RidgeCV(
    alphas=alphas,
    cv=10
)
```

即采用 10 折交叉验证选择最优 $\lambda$。

------

# 七、Lasso 回归

$$
Lasso 回归使用 L_1 正则化。

其目标函数为：

min⁡β[∑i=1n(yi−xiTβ)2+λ∑j=1p∣βj∣]\min_{\beta} \left[ \sum_{i=1}^{n} (y_i-\mathbf{x}_i^T\beta)^2 + \lambda \sum_{j=1}^{p}|\beta_j| \right]

与 Ridge 相比，Lasso 最大的特点是可以将部分回归系数直接压缩为 0。

即：

βj=0\beta_j = 0

表示对应变量没有进入最终模型。
$$

因此 Lasso 同时具有：

- 回归预测能力；
- 变量选择能力；
- 模型稀疏化能力。

本实验使用：

```python
LassoCV(
    alphas=alphas,
    cv=10,
    max_iter=100000
)
```

采用 10 折交叉验证选择最优 $\lambda$。

------

# 八、Elastic Net 回归

$$
Elastic Net 同时使用 L_1 和 L_2 两种正则化。

其目标函数可以表示为：

min⁡β[12n∑i=1n(yi−xiTβ)2+λ(α∑j=1p∣βj∣+1−α2∑j=1pβj2)]\min_{\beta} \left[ \frac{1}{2n} \sum_{i=1}^{n} (y_i-\mathbf{x}_i^T\beta)^2 + \lambda \left( \alpha\sum_{j=1}^{p}|\beta_j| + \frac{1-\alpha}{2} \sum_{j=1}^{p}\beta_j^2 \right) \right]

其中：

- \lambda 控制正则化强度；
- \alpha 控制 L_1 和 L_2 惩罚的比例。

当：

α=1\alpha = 1

Elastic Net 接近 Lasso。

当：

α=0\alpha = 0

Elastic Net 接近 Ridge。

因此 Elastic Net 综合了 Ridge 和 Lasso 的特点。
$$

本实验使用：

```python
ElasticNetCV(
    alphas=alphas,
    l1_ratio=l1_ratios,
    cv=10,
    max_iter=100000
)
```

同时通过 10 折交叉验证选择合适的 $\lambda$ 和 $\alpha$。

# 十一、三种模型比较

三种正则化模型的主要区别如下：

| 模型        | 正则化    | 变量选择 | 共线性处理 |
| ----------- | --------- | -------- | ---------- |
| Ridge       | $L_2$     | 较弱     | 较好       |
| Lasso       | $L_1$     | 较强     | 一般       |
| Elastic Net | $L_1+L_2$ | 较强     | 较好       |

Ridge 主要通过缩小系数来降低模型复杂度。

Lasso 可以将部分系数压缩为 0，因此具有明显的变量选择能力。

Elastic Net 综合了两种正则化方法，在变量选择的同时，可以利用 $L_2$ 惩罚缓解变量之间的相关性。

# 十二、1-SE 法则

$$
普通交叉验证一般选择使交叉验证误差最小的 \lambda：

λmin⁡=arg⁡min⁡λCV(λ)\lambda_{\min} = \arg\min_{\lambda} CV(\lambda)
$$

$$
这种方法可以获得交叉验证误差最低的模型。

但是，误差最低并不一定意味着模型最优。

如果两个模型的预测性能非常接近，那么通常应该选择更加简单的模型。

因此可以使用 1-SE 法则。

首先找到最小交叉验证误差：

CVmin⁡CV_{\min}

然后计算最小误差对应的标准误：

SEmin⁡SE_{\min}

构造允许范围：

CV(λ)≤CVmin⁡+SEmin⁡CV(\lambda) \leq CV_{\min}+SE_{\min}

在满足这个条件的模型中，选择正则化程度更强的模型。

通常表现为：

λ1SE>λmin⁡\lambda_{1SE} > \lambda_{\min}

也就是说，1-SE 法则倾向于选择更大的 \lambda。
$$



------

# 十三、1-SE 法则与模型稀疏性

$$
对于 Lasso：

λ↑⇒更多系数变成0\lambda \uparrow \Rightarrow \text{更多系数变成0}

因此采用 1-SE 法则后，Lasso 模型通常会变得更加稀疏。

对于 Elastic Net，也会因为更大的正则化强度而进一步压缩模型系数。

对于 Ridge，由于其采用 L_2 惩罚，即使增大 \lambda，系数通常也不会精确变成 0，因此变量数量不会像 Lasso 那样明显减少。

因此，如果 1-SE 模型与最小 CV 误差模型相比，测试集预测性能变化很小，但是非零变量数量明显减少，那么选择 1-SE 模型是合理的。

也就是说：

预测性能基本不变+模型复杂度降低\text{预测性能基本不变} + \text{模型复杂度降低}

通常比单纯追求最小交叉验证误差更加合理。
$$

# 十四、实验结论

$$
本实验使用 Hitters 数据集，对 Ridge、Lasso 和 Elastic Net 三种正则化回归方法进行了比较。

实验首先对数据进行了缺失值处理，将 `League`、`Division` 和 `NewLeague` 转换为哑变量，并对预测变量进行 Z-score 标准化。

随后分别使用 `RidgeCV`、`LassoCV` 和 `ElasticNetCV`，并采用 10 折交叉验证选择最优正则化参数。

Ridge 使用 L_2 正则化，可以有效压缩回归系数并缓解多重共线性，但通常不会产生精确为 0 的系数，因此变量选择能力较弱。

Lasso 使用 L_1 正则化，可以将部分系数直接压缩为 0，因此能够实现变量选择并得到稀疏模型。

Elastic Net 同时使用 L_1 和 L_2 正则化，在变量选择和处理相关变量方面具有综合优势。

最终可以根据测试集 RMSE 和非零变量数量对三种模型进行综合评价。

其中：

RMSE↓⇒预测性能提高RMSE \downarrow \Rightarrow \text{预测性能提高}

以及：

非零变量数↓⇒模型更加稀疏\text{非零变量数} \downarrow \Rightarrow \text{模型更加稀疏}

如果使用 1-SE 法则后，模型的预测性能没有明显下降，同时非零变量数量明显减少，那么应该选择 1-SE 模型。

因此，正则化模型的选择不能只考虑预测误差，还应该同时考虑：

预测精度+模型复杂度+可解释性\boxed{ \text{预测精度} + \text{模型复杂度} + \text{可解释性} }

综合来看，Lasso 和 Elastic Net 更适合需要进行变量筛选的场景，而 Ridge 更适合希望保留所有变量、同时降低多重共线性影响的场景。
$$
