# 基于 Elastic Net 的 Kaggle Netflix 数据分析

## 一、实验目的

本实验使用 Kaggle 上的 Netflix Movies and TV Shows 数据集，利用 Elastic Net 回归方法分析 Netflix 电影特征与电影时长之间的关系。

通过本实验，主要达到以下目的：

1. 掌握 Netflix 数据集的基本数据处理方法；
2. 对原始数据进行缺失值处理和特征工程；
3. 理解 Elastic Net 回归的基本原理；
4. 使用 Z-score 标准化处理数值变量；
5. 使用 Elastic Net 进行变量选择和回归分析；
6. 通过交叉验证选择最优的正则化参数；
7. 使用 MSE、RMSE、MAE 和 $R^2$ 对模型进行评价；
8. 根据 Elastic Net 的回归系数分析不同特征对电影时长的影响。

# 五、Elastic Net 回归模型

## 5.1 模型原理

Elastic Net 是结合 Lasso 回归和 Ridge 回归思想的一种正则化线性回归方法。

普通线性回归的目标函数为：

min⁡β12n∥y−Xβ∥22\min_{\beta} \frac{1}{2n} \|y-X\beta\|_2^2

Elastic Net 在此基础上加入 L1 和 L2 两种正则化项：

min⁡β{12n∥y−Xβ∥22+α[ρ∥β∥1+1−ρ2∥β∥22]}\min_{\beta} \left\{ \frac{1}{2n}\|y-X\beta\|_2^2+ \alpha \left[ \rho\|\beta\|_1+ \frac{1-\rho}{2}\|\beta\|_2^2 \right] \right\}

其中：

- $\alpha$ 表示总体正则化强度；
- $\rho$ 表示 L1 正则化所占的比例；
- L1 正则化具有变量选择作用；
- L2 正则化能够提高模型稳定性。

当：

ρ=1\rho=1

时，Elastic Net 等价于 Lasso。

当：

ρ=0\rho=0

时，Elastic Net 等价于 Ridge。

因此：

0<ρ<10<\rho<1

时，模型同时具有 Lasso 和 Ridge 的特点。

# 六、数据标准化

由于不同变量的取值范围不同，因此在进行正则化回归之前，需要对数值变量进行标准化。

本实验采用 Z-score 标准化：

z=x−xˉsz=\frac{x-\bar{x}}{s}

其中：

- $x$ 为原始数据；
- $\bar{x}$ 为变量均值；
- $s$ 为变量标准差。

标准化之后：

E(z)=0E(z)=0

并且：

Var(z)=1Var(z)=1

标准化可以避免不同变量的量纲差异对正则化惩罚产生影响，使 Elastic Net 对不同变量进行更加公平的系数收缩。

Elastic Net 最重要的特点之一就是能够通过 L1 正则化进行变量选择。

本实验中共有 3 个特征的系数被压缩为 0：

| 特征             | 系数 |
| ---------------- | ---- |
| `rating_NC-17`   | 0    |
| `rating_UR`      | 0    |
| `rating_Unknown` | 0    |

即：

3\boxed{3}

个变量被 Elastic Net 自动剔除。

这说明 Elastic Net 判断这些变量在当前模型中的独立解释贡献较小，因此将其回归系数压缩到了 0。

这正是 Elastic Net 与普通线性回归的重要区别之一。

# 十四、Elastic Net 的优势

本实验使用 Elastic Net 的主要原因是 Netflix 数据中包含多个具有潜在相关性的特征，并且分类变量经过 One-Hot 编码后会产生多个变量。

Elastic Net 同时结合了 L1 和 L2 正则化：

Elastic Net=L1+L2Elastic\ Net=L1+L2

其中 L1 正则化能够进行变量选择：

∣βj∣→0|\beta_j|\rightarrow0

甚至：

βj=0\beta_j=0

而 L2 正则化能够降低模型对单个变量的过度依赖，使模型更加稳定。

因此，Elastic Net 在处理多变量回归问题时具有较好的适用性。

# 十五、实验结论

本实验使用 Kaggle 上的 Netflix Movies and TV Shows 数据集，建立了 Elastic Net 回归模型，对 Netflix 电影时长进行了分析。

经过数据清洗和特征工程后，最终使用电影的发行年份、加入 Netflix 年份、演员数量、国家数量、类型数量、导演信息以及电影分级等变量作为特征，并以电影时长作为因变量。

通过 5 折交叉验证得到最优参数：

α=0.006551\boxed{\alpha=0.006551}l1_ratio=0.80\boxed{l1\_ratio=0.80}

说明当前模型中 L1 正则化占比较高，同时保留了一定的 L2 正则化。

模型在测试集上的结果为：

MSE=484.7847\boxed{MSE=484.7847}RMSE=22.0178\boxed{RMSE=22.0178}MAE=16.5753\boxed{MAE=16.5753}R2=0.3152\boxed{R^2=0.3152}

模型能够解释约 31.52% 的电影时长变化。

从特征系数来看，电影分级相关变量的影响较为明显，同时 `genre_count` 和 `cast_count` 也表现出较明显的正向关系。Elastic Net 最终将 `rating_NC-17`、`rating_UR` 和 `rating_Unknown` 三个变量的系数压缩为 0，实现了变量选择。

总体来看，Elastic Net 能够在 Netflix 数据中同时完成**回归预测、变量选择和特征影响分析**。虽然当前模型的预测能力仍然有限，但实验结果体现了 Elastic Net 在处理多变量回归问题中的实际应用价值。

# 十六、实验总结

通过本次实验，可以进一步理解正则化回归方法在实际数据分析中的应用。

与普通线性回归相比，Elastic Net 不仅可以拟合因变量与多个自变量之间的关系，还可以通过 L1 正则化剔除贡献较小的变量，并通过 L2 正则化提高模型稳定性。

本实验最终得到：

Elastic Net=L1 正则化+L2 正则化\boxed{ Elastic\ Net = L1\ 正则化 + L2\ 正则化 }

通过对 Kaggle Netflix 数据集进行分析，可以看到正则化方法不仅可以用于预测，还可以用于变量筛选和解释数据中的潜在关系。
