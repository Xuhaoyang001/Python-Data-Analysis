# 一、MNIST 手写数字二分类实验报告

## 一、实验目的

本实验使用支持向量机（SVM）对 MNIST 手写数字数据集中的数字 0 和数字 1 进行二分类识别。通过构建线性 SVM 和 RBF 核 SVM 两种模型，比较它们在分类准确率、精确率、召回率、F1 值以及训练时间等方面的表现，分析不同核函数对分类效果和计算效率的影响。

## 二、实验数据集

本实验使用 Kaggle 平台上的 Digit Recognizer 数据集。该数据集包含手写数字图像及其对应的数字标签，每张图像的尺寸为 (28\times28) 像素。

每张图像包含 784 个像素特征，数据集中原始标签包括数字 0 至数字 9。本实验仅保留数字 0 和数字 1，构建二分类数据集。

数据集基本信息如下：

| 项目               | 实验数据             |
| ------------------ | -------------------- |
| 原始数据集大小     | 42000 条样本，785 列 |
| 筛选后的数据集大小 | 8816 条样本，785 列  |
| 数字 0 的样本数    | 4132                 |
| 数字 1 的样本数    | 4684                 |
| 特征维度           | 784                  |
| 实际使用样本数     | 6000                 |
| 训练集样本数       | 4800                 |
| 测试集样本数       | 1200                 |

其中，785 列由 1 列标签和 784 列像素特征组成。为了降低 RBF 核 SVM 的训练开销，实验从筛选后的数据中抽取 6000 条样本，并按照 8:2 的比例划分训练集和测试集。

## 三、实验原理

### 3.1 支持向量机

支持向量机是一种监督学习算法，其基本思想是在特征空间中寻找一个能够区分不同类别的最优分类超平面，使分类间隔尽可能大，从而获得较好的泛化能力。

对于本实验，输入特征为 784 维像素向量，输出类别为数字 0 或数字 1。

### 3.2 线性 SVM

线性 SVM 使用线性决策函数对样本进行分类，其表达式为：
$$
[
f(x)=w^Tx+b
]
$$
其中，(x) 表示输入样本，(w) 为权重向量，(b) 为偏置项。

线性 SVM 的模型结构相对简单，训练速度通常较快，适合处理大规模、高维度数据。

本实验使用 `LinearSVC` 实现线性 SVM，并设置正则化参数 (C=1.0)。

### 3.3 RBF 核 SVM

RBF 核 SVM 通过高斯径向基核函数处理非线性分类问题，其核函数为：
$$
[
K(x_i,x_j)=
\exp\left(-\gamma|x_i-x_j|^2\right)
]
$$
其中，(x_i) 和 (x_j) 表示两个样本，(\gamma) 控制核函数的作用范围。

当样本之间的距离发生变化时，核函数能够反映它们之间的非线性关系，因此 RBF 核 SVM 可以构建更加灵活的分类边界。

本实验使用 `SVC` 实现 RBF 核 SVM，设置 (C=5.0)，并采用 `gamma="scale"` 自动确定核参数。

### 3.4 数据预处理

由于原始图像的像素值范围为 0 至 255，本实验将像素值除以 255，使其归一化至 0 至 1：
$$
[
x'=\frac{x}{255}
]
$$
归一化可以使输入特征处于统一的数值范围，有利于 SVM 模型的训练。

### 3.5 评价指标

本实验采用以下指标评价模型性能。

**准确率（Accuracy）：**
$$
[
Accuracy=\frac{TP+TN}{TP+TN+FP+FN}
]
$$
**精确率（Precision）：**
$$
[
Precision=\frac{TP}{TP+FP}
]
$$
**召回率（Recall）：**
$$
[
Recall=\frac{TP}{TP+FN}
]
$$
**F1 值：**
$$
[
F1=\frac{2\times Precision\times Recall}
{Precision+Recall}
]
$$
其中，(TP)、(TN)、(FP)、(FN) 分别表示真正例、真负例、假正例和假负例。

此外，通过记录模型训练开始与结束的时间，计算训练耗时，以比较两种模型的计算效率。

## 四、实验实现

实验使用 Python 编程语言，主要依赖 Pandas 和 Scikit-learn 库。

实验过程如下：

1. 读取 `train.csv` 文件，获取图像像素特征和对应标签。
2. 筛选标签为 0 和 1 的样本，构建二分类数据集。
3. 提取 784 维像素特征，并将像素值归一化至 0 至 1。
4. 抽取 6000 条样本，按照 8:2 的比例划分训练集和测试集。
5. 分别建立线性 SVM 和 RBF 核 SVM 模型。
6. 使用训练集训练模型，并记录训练时间。
7. 使用测试集进行预测，计算准确率、精确率、召回率和 F1 值。
8. 输出分类报告、混淆矩阵以及模型性能对比结果。

## 五、实验结果与分析

### 5.1 模型性能对比

根据程序实际运行结果，两种模型的性能如下：

| 模型       | 准确率  | 精确率  | 召回率  | F1 值   | 训练时间 |
| ---------- | ------- | ------- | ------- | ------- | -------- |
| 线性 SVM   | 100.00% | 100.00% | 100.00% | 100.00% | 0.114 秒 |
| RBF 核 SVM | 100.00% | 100.00% | 100.00% | 100.00% | 0.486 秒 |

从实验结果可以看出，两种模型在当前测试集上均实现了 100% 的分类准确率，精确率、召回率和 F1 值也均为 100%。

这表明在当前数据划分和参数设置下，数字 0 和数字 1 在像素特征空间中具有较强的可分性，线性 SVM 已经能够有效完成分类任务。

### 5.2 混淆矩阵分析

线性 SVM 的混淆矩阵为：
$$
[
\begin{bmatrix}
562 & 0\
0 & 638
\end{bmatrix}
]
$$
RBF 核 SVM 的混淆矩阵为：
$$
[
\begin{bmatrix}
562 & 0\
0 & 638
\end{bmatrix}
]
$$
混淆矩阵的行表示真实类别，列表示预测类别。在本实验中，数字 0 有 562 个测试样本，数字 1 有 638 个测试样本。

两个模型均正确识别了全部 1200 个测试样本，没有出现误分类情况。这与两种模型均达到 100% 准确率的结果一致。

### 5.3 训练时间分析

线性 SVM 的训练时间为 0.114 秒，RBF 核 SVM 的训练时间为 0.486 秒。

两种模型的训练时间相差：
$$
[
0.486-0.114=0.372\text{ 秒}
]
$$
RBF 核 SVM 的训练耗时约为线性 SVM 的 4.26 倍。

在本实验中，RBF 核 SVM 没有带来可观测的准确率提升，却需要更长的训练时间。因此，对于当前的 MNIST 0 与 1 二分类任务，线性 SVM 已经能够提供良好的分类效果，同时具有更高的计算效率。

需要注意，训练时间会受到计算机硬件、软件环境、数据规模和参数设置的影响，因此上述时间仅代表本次运行结果。

## 六、实验结论

本实验基于 Kaggle 的 Digit Recognizer 数据集，筛选数字 0 和数字 1，使用线性 SVM 与 RBF 核 SVM 完成手写数字二分类任务。

实验结果表明，两种模型在 1200 条测试样本上均取得了 100% 的准确率，且精确率、召回率和 F1 值均为 100%。这说明对于当前筛选出的两个数字类别，线性分类器已经能够有效地区分样本。

从计算效率来看，线性 SVM 的训练时间为 0.114 秒，而 RBF 核 SVM 的训练时间为 0.486 秒。在分类指标相同的情况下，线性 SVM 更适合当前实验场景。

本实验也表明，核函数更加复杂并不意味着测试准确率一定更高。当数据本身具有较强的线性可分性时，线性 SVM 可能已经足够有效；对于样本规模更大或分类边界更加复杂的任务，则可以进一步考虑 RBF 核 SVM、PCA 降维或核近似方法。

最后，本次实验使用的是 MNIST 中的 0 和 1 两个类别，不能据此推断模型对全部十个数字也具有相同的识别效果。此外，100% 的测试准确率仅反映当前测试集上的表现，若要进一步验证模型的泛化能力，还可以使用不同随机种子进行重复实验，或者采用交叉验证进行评估。





# 二、白血病基因表达分类实验报告

## 一、实验目的

1. 理解支持向量机（SVM）的基本原理及其在线性分类问题中的应用。
2. 掌握高维基因表达数据的读取、预处理和分类方法。
3. 使用留一交叉验证（LOOCV）评估不同分类算法的性能。
4. 比较线性 SVM、K 近邻算法（KNN）和决策树在白血病分类任务中的表现，分析不同算法的优缺点。

## 二、实验数据集

本实验使用经典的 ALL/AML 白血病基因表达数据集，通过基因表达特征区分两种白血病类型：

- ALL：急性淋巴细胞白血病。
- AML：急性髓系白血病。

数据集使用 `data_set_ALL_AML_train.csv` 作为基因表达数据文件，使用 `actual.csv` 作为样本标签文件。

数据集具有以下特点：

1. 样本数量较少，训练集包含 38 个样本。
2. 特征维度较高，每个样本包含 7129 个基因表达特征。
3. 样本数量远小于特征数量，即 (n \ll d)。
4. 类别分布不均衡，ALL 类别有 27 个样本，AML 类别有 11 个样本。

本实验的数据维度为 (38 \times 7129)，其中 38 表示样本数量，7129 表示基因特征数量。

## 三、实验原理

### 3.1 支持向量机（SVM）

支持向量机是一种基于间隔最大化思想的监督学习算法。对于线性可分的数据，SVM 寻找一个能够区分不同类别的最优超平面，使两类样本之间的分类间隔尽可能大。

线性 SVM 的分类函数可以表示为：
$$
[
f(x)=w^T x+b
]
$$
其中，(w) 为权重向量，(x) 为输入特征向量，(b) 为偏置项。

SVM 通过控制分类间隔和分类误差之间的平衡，提高模型对未知样本的泛化能力。

本实验采用线性核 SVM。由于基因表达数据具有特征维度高、样本数量少的特点，线性 SVM 能够在较高维度的特征空间中建立分类边界，适合此类分类任务。

### 3.2 K 近邻算法（KNN）

KNN 是一种基于距离的分类算法。对于待分类样本，算法计算其与训练样本之间的距离，选择距离最近的 (k) 个样本，并根据邻居的类别进行预测。

本实验设置：
$$
[
k=3
]
$$
由于基因表达数据的特征量纲可能影响距离计算，因此实验在 KNN 模型前使用标准化处理，使不同基因特征处于相对可比较的尺度。

### 3.3 决策树

决策树通过不断选择特征并划分数据，将样本划分到不同的类别中。其结构直观、可解释性较强，但在小样本、高维数据中可能对训练数据较为敏感，容易出现过拟合。

本实验使用决策树作为对比算法，观察其在白血病基因表达分类任务中的表现。

### 3.4 留一交叉验证（LOOCV）

留一交叉验证是一种适用于小样本数据集的模型评估方法。每次从数据集中取出一个样本作为测试样本，其余样本用于训练模型，重复执行，直到每个样本都作为测试样本一次。

本实验包含 38 个样本，因此每种算法需要执行 38 次训练和预测。

最终准确率为：
$$
[
Accuracy=\frac{\text{预测正确的样本数}}{\text{总样本数}}
]
$$
本实验在交叉验证的每一折中单独拟合相应的预处理步骤，避免利用测试样本的信息拟合标准化参数或缺失值填充值。

## 四、实验方法与实现

### 4.1 数据预处理

首先读取基因表达数据和标签文件，然后进行以下处理：

1. 识别数字形式的样本编号列。
2. 删除与基因表达量无关的 `call` 列，以及基因描述和基因编号字段。
3. 将基因表达矩阵转置，使每一行表示一个样本，每一列表示一个基因特征。
4. 根据样本编号将表达数据与 `actual.csv` 中的癌症标签对应。
5. 对缺失值进行中位数填充。
6. 在线性 SVM 和 KNN 的交叉验证流程中执行标准化处理。

经过预处理后，得到 38 个样本、7129 个基因特征的数据集。

### 4.2 模型设置

本实验比较以下三种分类算法：

| 算法     | 参数设置        | 评估方法 |
| -------- | --------------- | -------- |
| 线性 SVM | 线性核，C=1.0   | LOOCV    |
| KNN      | k=3             | LOOCV    |
| 决策树   | random_state=42 | LOOCV    |

使用准确率、宏平均精确率、宏平均召回率、宏平均 F1 分数和运行时间评价模型表现。

其中，宏平均指标分别计算 ALL 和 AML 两个类别的指标，再对两个类别进行等权平均，能够降低类别数量不均衡对整体评价的影响。

## 五、实验结果与分析

### 5.1 三种算法的整体结果

根据程序运行结果，得到如下数据：

| 算法       | 准确率 | 宏平均精确率 | 宏平均召回率 | 宏平均 F1 | 运行时间（秒） |
| ---------- | ------ | ------------ | ------------ | --------- | -------------- |
| 线性 SVM   | 94.74% | 96.55%       | 90.91%       | 93.21%    | 1.2246         |
| KNN（k=3） | 92.11% | 95.00%       | 86.36%       | 89.47%    | 1.3369         |
| 决策树     | 94.74% | 96.55%       | 90.91%       | 93.21%    | 1.6573         |

从结果可以看出，线性 SVM 和决策树的准确率均为 94.74%，高于 KNN 的 92.11%。

线性 SVM 的运行时间约为 1.22 秒，在三种算法中最短。决策树虽然取得了与线性 SVM 相同的分类指标，但运行时间相对较长。

KNN 的准确率为 92.11%，说明其在当前数据集上也具有一定的分类能力，但整体表现略低于另外两种算法。

### 5.2 线性 SVM 结果分析

线性 SVM 的交叉验证准确率为：
$$
[
Accuracy=\frac{36}{38}\approx 94.74%
]
$$
模型正确分类了 38 个样本中的 36 个样本，错误分类了 2 个样本。

其混淆矩阵为：

| 真实类别 | 预测为 ALL | 预测为 AML |
| -------- | ---------- | ---------- |
| ALL      | 27         | 0          |
| AML      | 2          | 9          |

从混淆矩阵可以看出：

1. 27 个 ALL 样本全部被正确分类。
2. 11 个 AML 样本中，有 9 个被正确分类，2 个被误判为 ALL。
3. ALL 类别的召回率为 100%，AML 类别的召回率约为 81.82%。

这表明线性 SVM 对当前数据中的 ALL 样本识别效果较好，但仍有少量 AML 样本未能正确识别。

线性 SVM 的宏平均 F1 分数为 93.21%，说明模型在两个类别上的综合分类表现较好。

### 5.3 KNN 结果分析

KNN 的交叉验证准确率为 92.11%，对应正确分类 35 个样本，错误分类 3 个样本。

其混淆矩阵为：

| 真实类别 | 预测为 ALL | 预测为 AML |
| -------- | ---------- | ---------- |
| ALL      | 27         | 0          |
| AML      | 3          | 8          |

从结果可以看出：

1. 27 个 ALL 样本全部被正确分类。
2. 11 个 AML 样本中，有 8 个被正确分类，3 个被误判为 ALL。
3. AML 类别的召回率约为 72.73%，低于线性 SVM。

KNN 主要依据邻近样本进行分类。在高维数据中，距离度量可能难以充分体现样本之间的有效相似性，因此其分类表现可能受到高维特征空间的影响。

### 5.4 决策树结果分析

决策树的交叉验证准确率为 94.74%，宏平均 F1 分数为 93.21%，与线性 SVM 的结果相同。

其混淆矩阵为：

| 真实类别 | 预测为 ALL | 预测为 AML |
| -------- | ---------- | ---------- |
| ALL      | 27         | 0          |
| AML      | 2          | 9          |

这说明决策树在本次实验中的预测结果与线性 SVM 一致。不过，两种模型得到相同的预测指标，并不意味着它们使用了相同的分类机制，也不能据此认定它们对其他样本具有相同的泛化能力。

决策树可以通过特征划分形成分类规则，但在样本较少、特征较多的情况下，模型可能对数据变化较为敏感，因此仍需要进一步验证其稳定性。

### 5.5 综合比较

综合三种算法的实验结果：

1. **分类准确率方面：** 线性 SVM 和决策树并列第一，准确率均为 94.74%。
2. **宏平均 F1 方面：** 线性 SVM 和决策树均为 93.21%，高于 KNN 的 89.47%。
3. **运行效率方面：** 线性 SVM 的运行时间最短，约为 1.22 秒。
4. **AML 识别方面：** 线性 SVM 和决策树的 AML 召回率均约为 81.82%，KNN 约为 72.73%。

因此，在线性 SVM 和决策树分类指标相同的情况下，线性 SVM 具有更短的运行时间，是本次实验中更合适的优先选择。

需要注意的是，本实验样本数量仅为 38，单个样本的分类结果就会明显影响最终准确率。此外，三个模型使用相同的数据集和交叉验证方式，其结果只能反映当前实验设置下的表现，不能直接推广到所有白血病样本。

## 六、实验结论

本实验使用白血病基因表达数据集，对线性 SVM、KNN 和决策树三种分类算法进行了比较，并采用留一交叉验证评估模型性能。

实验结果表明，线性 SVM 和决策树均取得了 94.74% 的准确率，宏平均 F1 分数均为 93.21%；KNN 的准确率为 92.11%，宏平均 F1 分数为 89.47%。线性 SVM 的运行时间最短，综合表现较好。

由于本数据集具有样本少、特征维度高的特点，线性 SVM 能够在高维空间中建立有效的分类边界，体现出较好的分类性能。实验也说明，算法的表现不仅取决于特征维度，还与样本数量、类别分布、预处理方式和模型参数有关。

本次实验的结果来自 38 个训练样本的留一交叉验证，不能直接视为模型在独立测试集上的表现。后续可以使用 `data_set_ALL_AML_independent.csv` 对训练完成的模型进行独立测试，以进一步评价模型的泛化能力。

通过本次实验，掌握了高维基因表达数据的预处理方法、留一交叉验证的基本流程，以及使用多种分类算法进行性能比较的方法，加深了对 SVM 在小样本、高维分类问题中应用价值的理解。
